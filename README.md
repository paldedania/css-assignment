# CSS assignments

Open any exercise's HTML file in a browser. The pages use HTML and CSS from the techniques covered in the [CodingGita CSS course](https://github.com/codinggita/CGxSU_Semester_1/tree/main/Semester_1/html_css_js(sem_01)/CSS) and load their images and stylesheets from this repository.

## Level 1

1. [Selectors](01.level_1/01.selectors/assignment1-selectors.html)
2. [Colors and backgrounds](01.level_1/02.colors/assignment2-colors-backgrounds.html)
3. [Box model and borders](01.level_1/03.box_model/assignment3-boxmodel-borders.html)
4. [Text and fonts](01.level_1/assignment4-text-fonts/assignment4-text-fonts.html)
5. [Links and icons](01.level_1/05.links_%26_icons/assignment5-links-icons.html)

The text and fonts exercise uses a local font stack. The colors exercise uses a fixed background on wider screens and a scrolling background on smaller screens.
